En gros la range sert à décider si on veut dessiner tout le tableau ou pas.


. prepare_batches(instances, range) :

	La range sélectionne les instances à dessiner dans le tableau fourni.

	La fonction :

	Résout les ressources depuis l’arena du contexte global, accessible implicitement. Prépare les données GPU. Regroupe les instances consécutives compatibles en 	batches. Conserve l’ordre du tableau pour respecter les superpositions et la transparence. Retourne les batches sans effectuer de draw call. Le verrou de l’arena est 	conservé uniquement le temps de récupérer les ressources et de cloner les handles nécessaires. Il est relâché avant la préparation GPU et le dessin.
	Un batch partage le même pipeline, les mêmes états de rendu et la même ressource de texture. Les couches d’une même texture array ou les régions d’un même atlas 	peuvent varier dans un batch.

draw(batch, pass) :

	La fonction :

	Reçoit un batch préparé, valide et non vide. Bind automatiquement les ressources de texture. Effectue exactement un draw call. Utilise le pipeline compatible bindé en 	amont.

	Ne prend aucun verrou sur l’arena, car le batch conserve les handles nécessaires.

draw_all(instances, range, pass) :

	La fonction combine :

	L’appel à prepare_batches(). La boucle sur les batches. L’appel à draw() pour chaque batch.

	Elle peut donc effectuer plusieurs draw calls.
	Une plage vide ne produit aucun draw call.

Utilisation explicite :

backend::bind(&*ctx, pass);

let batches = prepare_batches(&instances, range)?;
for batch in &batches {
	draw(batch, pass)?;
}

Utilisation automatique :

backend::bind(&*ctx, pass);
draw_all(&instances, range, pass)?;

Les noms et signatures restent indicatifs.

L’utilisateur n’a plus à écrire les changements de bind groups ni les appels à draw_indexed.
